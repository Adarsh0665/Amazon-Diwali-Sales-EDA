# Amazon Diwali Sales EDA 🎆📊

## 📌 Project Overview
This project performs **Exploratory Data Analysis (EDA)** on Amazon Diwali sales data to uncover meaningful insights related to customer behavior, product categories, payment methods, and overall sales performance during the Diwali festival season.

The analysis is done using **Python** and focuses on understanding trends, patterns, and key business metrics.

---

## 🎯 Objectives
- Analyze total sales and revenue distribution
- Understand customer purchasing behavior
- Identify top-selling product categories
- Analyze payment methods and delivery status
- Generate visual insights for better decision-making

---

## 🗂️ Dataset Information
- **Source:** Kaggle  
- **Dataset Name:** Amazon Product Sales – Diwali Season  
- **Format:** CSV  
- **Currency:** INR (₹)

### Key Columns:
- Order ID  
- Date  
- Customer ID  
- Product Category  
- Product Name  
- Quantity  
- Unit Price (INR)  
- Total Sales (INR)  
- Payment Method  
- Delivery Status  

---

## 🛠️ Tools & Technologies Used
- Python 🐍
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Seaborn

---

## 📊 Analysis Performed
- Data cleaning and preprocessing
- Handling missing values
- Descriptive statistics
- Category-wise sales analysis
- Visualization of sales trends
- Customer and payment method analysis

---

## 📈 Key Insights
- Certain product categories dominate Diwali sales
- Digital payment methods are highly preferred
- High demand observed during peak festival days
- Significant variation in sales across categories
